# مصاريفي — لوحة الإدارة 7.6.0

مستودع الإدارة: https://github.com/wowmobilya/Masarifi.admin132453294

عنوان اللوحة بعد تفعيل GitHub Pages: https://wowmobilya.github.io/Masarifi.admin132453294/

تطبيق المستخدم: https://wowmobilya.github.io/Masarifi/

هذه لوحة فعلية مرتبطة بخادم مصاريفي نفسه. تعرض الحسابات والأجهزة والاشتراكات والمدفوعات وقياسات المزامنة والرسائل؛ لا تعرض محتوى ماليًا خاصًا دون موافقة دعم محددة.

## التشغيل

1. ارفع محتويات حزمة الإدارة إلى جذر هذا المستودع؛ يصبح `index.html` ملف اللوحة.
2. في Settings → Pages اختر النشر من `main` و`/(root)`.
3. افتح عنوان اللوحة، وأدخل رمز التهيئة الخاص الذي تسلّمه المالك بصورة منفصلة. صالح لمدة محددة ولمرة واحدة. **لا ترفعه إلى GitHub**.
4. بعد التوثيق تفتح اللوحة مباشرة على الجهاز نفسه. احفظ «رمز استعادة الإدارة» في مكان خاص قبل فصل الجهاز أو مسح بيانات المتصفح.
5. اضبط تعليمات الدفع ورقم واتساب وبريد استقبال الطلبات من قسم العرض والدفع. ابحث بكود البرنامج أو معرّف المستخدم لتفعيل النسخة الصحيحة، وسجّل التحقق الفعلي من الدفع قبل التفعيل.

لا توجد كلمة مرور إدارية عامة. المستودع عام واسم الرابط ليس وسيلة حماية. الجلسة المعتمدة وصلاحيات الخادم هما الحماية، ورمز البرنامج العام لا يسمح بالدخول. لا تحتوي الواجهة على مفتاح خدمة الخادم.

النسختان على GitHub Pages لهما المسار نفسه من حيث النطاق `wowmobilya.github.io`، ولذلك فصل المستودعين لا يساوي عزل النطاق في المتصفح. مفاتيح جلساتهما وأماكن حفظ الهوية منفصلة، والخادم يفرض الصلاحيات. عند تجهيز نطاق خاص، يُفضّل وضع الإدارة على نطاق مستقل وتحديث قائمة Origins لخدمة الهوية.

## بناء الواجهة وتشغيل الخادم

`python3 tools/build-admin.py` يعيد بناء `index.html` من `admin/` والملفات العامة في `assets/`. لا يلزم npm للنشر الثابت.

ملفات `supabase/` هي مصدر الخادم المشترك. التحديث التراكمي 7.6 موجود في `patches/v760_identity.sql` وخدمة `functions/masarifi-identity`. لا تُطبّق التحديث مرتين على خادم مُحدّث، ولا تنفذ كل ملفات الترحيل عشوائيًا. اقرأ `docs/OPERATIONS_AR.md` للتشغيل والتحديثات السابقة.

خدمة الهوية تحتاج تفعيل Anonymous Sign-ins في Supabase Auth لإنشاء الهوية المؤقتة، ثم تحولها خدمة موثقة إلى هوية جهاز مستقلة. هذا لا يتيح للهويات المجهولة استدعاء واجهات المال أو الإدارة. عنوان البريد الداخلي للهوية تقني وغير قابل لاستقبال الرسائل؛ الاستعادة بالرمز الخاص فقط.

رموز الاستعادة تمنح الوصول لصاحبها. لا يمكن للإدارة قراءتها أو معرفة كلمات مرور المستخدمين أو رمز القفل المحلي. الجهاز الذي لم يتصل بالخادم قط لا يظهر في الإحصاءات، واستهلاك الخادم المعروض يقيس طلبات المزامنة المحددة ولا يمثل كامل فاتورة الاستضافة.
